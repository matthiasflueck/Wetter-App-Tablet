# Wetter-App Tablet

Installierbare Web-App für die Wetter-App. Dieses Repository enthält nur die öffentliche Oberfläche. Messdaten, Einstellungen und Anmeldetokens sind nicht enthalten. Private Daten werden nach Google-Anmeldung aus dem App-Datenbereich geladen und lokal offline gespeichert.

Die Google-Web-Client-ID wird nach Einrichtung der Hosting-Adresse ergänzt. Bis dahin bleibt die Google-Anmeldung deaktiviert.

Für GitHub Pages: main → / (root).
